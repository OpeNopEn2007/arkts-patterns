## 检查清单

### 1. primary-acceptance-flow

操作：按本实验主要用户路径操作一次；请在本地化时替换为具体输入和点击步骤。

预期结果：主要功能满足实验要求，关键文本、状态和反馈正确。

评分：0-2。0 = 失败，1 = 部分通过，2 = 完全通过。

### 2. edge-case-feedback

操作：尝试一个空输入、非法输入或未准备状态下的操作。

预期结果：应用给出友好反馈，不崩溃，不出现明显乱码。

评分：0-2。0 = 失败，1 = 部分通过，2 = 完全通过。

### 3. ui-basic-usability

操作：把所有可见按钮、输入框、标签页或列表项至少操作一次。

预期结果：没有明显布局破损、无响应控件或令人困惑的反馈。

评分：0-2。0 = 失败，1 = 部分通过，2 = 完全通过。

## 阻塞失败

- Previewer 无法渲染目标页面。
- 执行任一必测检查项时应用崩溃。
